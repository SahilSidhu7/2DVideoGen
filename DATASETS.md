# DATASETS.md - what this project trained and measured on

Every dataset used across 24 attempts, where it came from, what it was for, and
whether it is in this repository. **None of the bulk data is committed** - it is
either synthesised by a script in this repo or downloaded by a fetcher in this
repo, so every row below is reproducible from a clean clone.

---

## 1. The data that produced the shipped models

The scene-script writers (`v1` through `v4`) are trained on **synthetic
prompt/DSL pairs**, generated locally. There is no scraped text in this path.

| dataset | rows | generated by | used by |
|---|--:|---|---|
| `scene_train.jsonl` / `scene_val.jsonl` | 6000 / 700 | `model/scene_synth.py --n 6000 --val 700` | `v1-confounded` |
| `scene2_*.jsonl` | 6000 / 700 | `... --deconfound` | `v2-deconfounded` |
| `scene3_*.jsonl` | 6000 / 700 | `... --deconfound --stage --max-cast 8` | `v3-staged`, **`v4-base`** |

Preserved next to the weights that consumed them, in
`model/checkpoints/<version>/data/`, so a checkpoint can never drift from its
training set. Val prompts are filtered disjoint from train.

**The most important thing on this page is a defect in row one.** In
`scene_train.jsonl`, clause count equalled cast size in **5 681 of 5 688**
examples (99.9%). The model looked unable to count a cast; it had in fact
learned to count *clauses*, because the data never asked it to do anything
else. `--deconfound` states the count while describing only a random subset of
the cast, and cuts that co-occurrence to 68.0%. Generalisation gap fell from
65.7 to 23.5 points. A dataset can teach a shortcut so cleanly that the model
looks incapable.

## 2. Real-image and real-pose data (the closed diffusion path)

| dataset | size | source | used for |
|---|--:|---|---|
| COCO **val2017** | 5 000 photos | `cocodataset.org`, auto-downloaded | YOLO11-pose -> 5 051 real person poses -> 14-d pose vectors; trained `ImgPoseNet_real` |
| COCO **128** | 128 images | ultralytics sample | smoke tests |
| `datasets/videos` | 5 clips | Wikimedia Commons (CC/PD) | real video -> per-frame equations |
| `datasets/videos_side` | 30 GIFs | Wikimedia Commons - **Eadweard Muybridge, *Animal Locomotion* (1887)**, public domain | side-on gait reference; titles in `datasets/_side_titles.json` |
| `datasets/pd_anime` | 5 films | `archive.org`, fetched by `svg/fetch_clips.py` | animation style reference: Fleischer *Superman* (1942) x3, *Superman* compilation, *The Betty Boop Limited* (1932) - all verified public domain |
| `datasets/lottie` | small | Lottie samples | vector-animation format probes |

**Licensing was a selection criterion, not an afterthought.** Every video frame
this project ever looked at is public domain or openly licensed. The Muybridge
plates are 1887; the Fleischer cartoons are lapsed-copyright US animation.

## 3. Data that exists only to be deleted

`svg/data/` held LoRA corpora and trainer state for the styled-anime route -
6.2 GB at peak. That route is **closed by measurement** (flicker 25.0x against
an 8x bar; pose obedience got *worse* when the motion module was added), so the
image and tensor bulk was deleted and only the logs, adapters and JSON results
were kept. The commands that regenerate it are in `paper/PAPER.md`.

## 4. Reproducing all of it

```bash
# synthetic scene-script data (what the shipped models actually use)
python model/scene_synth.py --n 6000 --val 700 --outdir model/data \
    --prefix scene3 --deconfound --stage --max-cast 8

# public-domain animation clips
python svg/fetch_clips.py

# COCO val2017 + real pose labels (GPU; routes through tools/gpuguard.py)
python model/build_real_dataset.py
```

## 5. What is committed

Scene scripts (`scenes/*.scene`), evaluation outputs (`model/eval_out*/`),
rendered videos (`out/*.mp4`) and documentation. **Model weights and bulk data
are not** - see `model/MODELS.md` for what each checkpoint was trained on and
how to reproduce it.
