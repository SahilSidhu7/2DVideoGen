# scenes/

Scene scripts for the compositor [`scenescript.py`](../scenescript.py), plus one
JSON scene for the equation renderer [`geovid.py`](../geovid.py).

## Script format

Line based; `#` starts a comment and blank lines are ignored. The authoritative
description is the docstring at the top of `scenescript.py`.

```
title      A meeting in the park
size       854 480
fps        30
seconds    9
background park

prop tree  at 1.5 scale 1.2
prop ball  at 6.2

cast ana color cyan   at 1.0 scale 1.00
cast bo  color orange at 8.6 scale 0.78

0.0 3.4 ana walk to 3.4
3.6 5.2 ana wave
4.0 6.0 bo  kick ball at ana
```

- **Header:** `title`, `size W H`, `fps`, `seconds`, `background`.
- **`prop <kind> [<name>] at <x> [scale S] [y Y]`:** scenery or objects. The
  hand-written scenes use kinds `tree`, `bush`, `rock`, `cloud`, `sun`, `box`
  and `ball`. Backgrounds seen in this directory are `park`, `night` and
  `studio`.
- **`cast <name> color <colour> at <x> [scale S] [y Y]`:** a character with its
  own identity, position and scale.
- **Timeline line:** `<start> <end> <who> <action> [to X] [at TARGET]`.
  Actions are `walk`, `run`, `jump`, `kick`, `wave`, `dance`, `idle`.

Each character has an independent timeline. `scenescript.py` also accepts a
JSON file with the same keys (a `.json` path, or text starting with `{`).

## Files

| file | what it is |
|---|---|
| `park_meet.scene` | Attempt 21 reference scene, hand-written. Two friends meet in a park and pass a ball while a third crosses the background (3 characters, 7 props). Rendered as `out/a21_park.mp4`. |
| `street_relay.scene` | Attempt 21 "fresh" script, written after the engine was frozen to test that the mechanism generalises. Night background, a three-way ball relay, different cast size, props and action mix. Rendered as `out/a21_street.mp4`. |
| `a22_generated.scene` | Attempt 22: the first scene written by the model, from the prompt "two friends meet in the park, one waves, then they kick a ball around". |
| `a22_generated3.scene` | Attempt 22: a second model-written scene, from an out-of-distribution prompt with a group action and a three-way structure. |
| `a22_batch_ind0..4.scene` | Attempt 22 batch of five scenes from held-out **in-distribution** prompts (`ind`). |
| `a22_batch_ood0..4.scene` | Attempt 22 batch of five scenes from **out-of-distribution** prompts (`ood`). |
| `a23_generated.scene` | Attempt 23: the same prompt as `a22_generated`, decoded with `--sample --unique-colours --rerank 4 --seed 23`. |
| `a23_six.scene` | Attempt 23: a six-character night-street scene ("six friends spread out on a night street, all of them dancing"). |
| `a24_six.scene` | Attempt 24: the same six-character prompt, written by the 220M model. |
| `my_scene.json` | Not a scene script. A `geovid.py` scene: an 854×480, 30 fps, 8 s Lissajous parametric curve plus a sine curve. |

Files that start with `# generated by model/scene_infer.py` were written by the
model; the others were written by hand. The context for each attempt is in
[`../ATTEMPTS.md`](../ATTEMPTS.md) (Attempts 21–24).

## Rendering

```bash
# a scene script -> mp4 (add --frames to also keep the PNG frames)
python scenescript.py scenes/park_meet.scene -o out/park.mp4 --frames out/park_frames

# check which characters are visible in rendered frames
python scenescript.py scenes/park_meet.scene --audit out/park_frames

# built-in self test
python scenescript.py --selftest

# the JSON equation scene
python geovid.py render scenes/my_scene.json -o out/my.mp4
```

`scenescript.py` also takes `--seconds` to override the script's duration.

To generate a script from a prompt (see the root README quickstart):

```bash
USE_TF=0 python model/scene_infer.py "two friends meet in the park" \
    --ckpt model/checkpoints/v3-staged --sample --unique-colours -o scenes/mine.scene
```

Model weights are not in the repository; see [`../model/MODELS.md`](../model/MODELS.md).
